# Overview

The main application window represents provides you with a view of the
catalog, and means to work with it.

[]

You can:

- import images, either from an existing location or from your camera.
- navigate into the catalog, finding pictures based on metadata, date
  or keywords.
- organise your images, grouping them physically.
- edit your photos in the darkroom.

The bottom show the film strip which is the list of the images being
used in the current "view", and which one are selected.

The left is the workspace and show various organisational features for
the catalog.

At the top you can activate the modules that allow to do different
things. Darkroom and Map respectively allow you to edit the images,
and to geo locate images on a map.
