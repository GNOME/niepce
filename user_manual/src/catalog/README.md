# Catalog

The catalog is what manages and hold information of your
photos. Working with Niepce is working with a catalog of images (and
videos). The user interface presented by Niepce is a view into the
current catalog.

You start with an empty catalog, add images either from your existing
collection or that you just took with your camera.

Then you navigate into the catalog, select images based on criterias.

Then you organise your images in albums or otherwise. You can also
organise your images in folders.

And then edit individual images in the darkroom.
