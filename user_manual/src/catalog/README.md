# Catalog

The catalog in Niepce is what manages and hold information of your
collection of picturees. Working with Niepce is working with a catalog
of photos (and videos). The catalog itself only handle the
organisation of the image, including with albums and keywords, and
helps organising the files on disk. The user interface presented by
Niepce is a view into the current catalog.

You start with an empty catalog, add images either from your existing
collection or that you just took with your camera.

Then you navigate into the catalog, select images based on criterias.

Then you organise your images in albums or otherwise. You can also
organise your images in folders.

And then edit individual images in the darkroom.

You can have as many catalogs as you want, and several catalog can
reference the same images, however we don't really recomend this.
